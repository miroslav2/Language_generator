# 🌐 Language Generator

> Инструмент для процедурной генерации искусственных языков (конлангов)

**Версия:** 0.1 Alpha · **Python:** 3.10+ · **Статус:** В разработке

---

## О проекте

Language Generator — это платформа для моделирования искусственных языков как **взаимосвязанных систем правил**, а не просто генераторов случайных слов.

Проект ориентирован на академическую лингвистику и ксенолингвистику. Поддерживает как человекоподобные языки (с исключениями, мутациями корней, сложной фонетикой), так и экзотические формы коммуникации — визуальные сигналы, нелинейный синтаксис, негуманоидные паттерны.

**Ключевые идеи:**

- **Универсальная единица сигнала** (`SignalUnit`) — абстракция над звуком, жестом, цветом или радиоимпульсом
- **Вероятностная фонотактика** — генерация слогов по системе весов (частые `CV` vs редкие `CCCV`)
- **Глубокая морфология** — супплетивизм (`go → went`), аблаут (`sing → sang`), внутренняя флексия, сложные композиты
- **Динамическая орфография** — умная токенизация, поддержка циркумфиксов, слитного написания и нестандартной пунктуации

## Архитектура

Проект построен на принципах модульности и разделения ответственности. Генерация — это пайплайн: выходные данные одного модуля становятся входными для следующего.

```
Language_generator/
│
├── main.py                  # Точка входа
├── requirements.txt
│
├── core/                    # Ядро: абстракции и базовые структуры
│   ├── interfaces.py        # SignalUnit, IModule
│   ├── data_structures.py   # Lexeme, Word, Morpheme
│   ├── project.py           # Управление проектом
│   └── state.py             # State Machine языка
│
├── modules/                 # Логические модули
│   ├── phonology/           # Генерация звуков и слогов
│   ├── morphology/          # Словообразование и мутации корней
│   ├── orthography/         # Письменность и рендеринг
│   └── lexicon/             # Словарный запас (семантика → лексемы)
│
├── ui/
│   └── debug_launcher.py    # Консольная утилита (Dev Mode)
│
└── resources/
    ├── ipa_db.json          # База звуков IPA
    ├── concepts.json        # Семантическое ядро (списки Сводеша)
    └── presets/             # Пресеты: Germanic, Slavic, Xeno...
```

### Пайплайн генерации

```
Phonology → Lexicon → Morphology (Mutation) → Morphology (Compounding) → Orthography
```

1. **Phonology** — из базы IPA формируется инвентарь звуков; `WeightedSyllableGenerator` создаёт шаблоны слогов
2. **Lexicon** — для каждого понятия (например, из списка Сводеша) создаётся лексема
3. **Morphology / Mutation** — `StemManager` применяет исключения или правила изменения корня
4. **Morphology / Compounding** — `CompoundEngine` склеивает корни с интерфиксами
5. **Orthography** — транслитерация, расстановка разделителей и знаков препинания

## Установка

```bash
# Клонирование
git clone https://github.com/miroslav2/Language_generator.git
cd Language_generator

# Виртуальное окружение (рекомендуется)
python -m venv venv
venv\Scripts\activate        # Windows CMD
# или
venv\Scripts\Activate.ps1    # PowerShell

# Зависимости
pip install -r requirements.txt
```

> **PowerShell:** если возникает ошибка прав доступа — выполните `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser`

```bash
# Запуск (режим отладки)
python main.py
```

## Конфигурация

Поведение задаётся через JSON-файлы в `resources/`.

**Лексема с исключениями:**
```json
{
  "meaning": "видеть",
  "base_form": "seh",
  "word_class": "strong_verb_class_5",
  "irregularities": {
    "past_tense": "sah",
    "past_participle": "gesehen"
  }
}
```

**Пунктуация:**
```json
"question_mark": {
  "symbol": "¿|?",
  "position": "circumfix",
  "space_rules": "none"
}
```
