📖 О проекте

Ultimate Language Generator — это профессиональная платформа для процедурной генерации, моделирования и развития искусственных языков (конлангов).

В отличие от простых генераторов случайных слов, ULG строит язык как взаимосвязанную систему правил. Проект разработан с учетом требований академической лингвистики и ксенолингвистики. Он позволяет моделировать как естественные человеческие языки (с их исключениями, мутациями корней и сложной фонетикой), так и формы общения иных цивилизаций (визуальные сигналы, нелинейный синтаксис).
Ключевые особенности

    Универсальная единица сигнала (SignalUnit): Абстракция, позволяющая работать не только со звуками (IPA), но и с цветом, жестами или радиоимпульсами.
    Вероятностная фонотактика: Генерация слогов на основе системы весов (например, частые CV vs редкие CCCV).
    Глубокая морфология: Поддержка супплетивизма (go -> went), аблаута (sing -> sang), внутренней флексии и сложного словосложения (Donaudampfschiffahrt).
    Динамическая орфография: Умная токенизация (поддержка слитного написания, смысловых разделителей) и сложная пунктуация (префиксы, циркумфиксы, оверлеи).

⚙️ Как это работает (Pipeline)

Генерация происходит поэтапно. Выходные данные одного модуля становятся входными для следующего.

    Phonology: Из базы IPA выбирается инвентарь звуков. WeightedSyllableGenerator создает шаблоны слогов (например, CVC с вероятностью 40%).
    Lexicon Generation: Для базового понятия (например, "ID_1: Я") создается лексема.
    Morphology (Mutation): Если слово используется в контексте (например, Прошедшее время), StemManager проверяет наличие исключений (супплетивизм) или применяет правила изменения корня.
    Morphology (Compounding): Если генерируется сложное понятие, CompoundEngine склеивает корни, добавляя интерфиксы (соединительные гласные).
    Orthography:
        Звуки транслитерируются в текст.
        WordSeparator определяет, как отделить слово от соседей (пробел, дефис или ничего).
        PunctuationManager расставляет знаки (в начале, конце или вокруг фразы).

🚀 Установка и Запуск
Предварительные требования

    Python 3.10 или выше.

1. Настройка окружения

Рекомендуется использовать виртуальное окружение.

Bash

# Создание venv (Windows)
python -m venv venv

# Активация
# PowerShell:
venv\Scripts\Activate.ps1
# CMD:
venv\Scripts\activate.bat

Если возникают ошибки с правами доступа в PowerShell:

PowerShell

Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

2. Установка зависимостей

(На данном этапе внешних библиотек нет, но в будущем для UI потребуется PyQt6)

Bash

pip install -r requirements.txt

3. Запуск

Режим разработки (Debug Console):
Позволяет тестировать отдельные модули без графического интерфейса.

Bash

python main.py

(По умолчанию main.py сейчас настроен на вызов DebugRunner)
🛠 Конфигурация и Пресеты

Программа управляется через JSON-файлы в папке resources/.
Пример структуры Лексемы (Lexeme)

Позволяет задавать "сильные" глаголы и исключения.

JSON

{
    "meaning": "видеть",
    "base_form": "seh",
    "word_class": "strong_verb_class_5",
    "irregularities": {
        "past_participle": "gesehen",
        "past_tense": "sah"
    }
}

Пример настройки Пунктуации

JSON

"question_mark": {
    "symbol": "¿|?",
    "position": "circumfix", 
    "space_rules": "none"
}

📅 План разработки (Roadmap)

    Core: Разработка базовой архитектуры и абстрактных классов.
    Structure: Организация файловой системы и скрипт инициализации.
    Phonology: Реализация генератора слогов с весами.
    Morphology: Реализация движка мутаций (StemManager).
    Orthography: Реализация динамических разделителей слов.
    UI: Создание графического интерфейса на PyQt6.
    Xeno: Добавление пресетов для негуманоидных форм общения.
